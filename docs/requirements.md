# 需求說明

一個不用註冊登入的**匿名聊天室**，所有人在同一個聊天室裡。技術與架構見 `architecture.md`，使用方式見 `../README.md`。

## 使用流程

打開網頁 → 在「代號」輸入框輸入代號 → 按「進入聊天室」→ 進到共用的聊天室。

## 已確認的需求

| 項目 | 決定 |
|---|---|
| 形式 | 一個所有人共用的聊天室，沒有分房間 |
| 進入方式 | 先看到進入畫面，輸入代號（去頭尾空白後 1～12 字）並按「進入聊天室」才連線；不用註冊、不用密碼 |
| 身分 | 名稱＝代號＋「#」＋資料庫產生的 3 碼編號（例如「小明#371」）；編號不能自己指定，同一個匿名身分固定不變 |
| 歷史訊息 | 進入時看到最近 50 則；往上按「載入更早的訊息」可再載入 50 則（聊天室累積超過 50 則才會出現這個按鈕） |
| 訊息內容 | 純文字，1～500 字；發出後不能編輯、刪除 |
| 即時性 | 別人發的訊息即時出現，不用重新整理 |
| 在線 | 顯示「N 人在線」，可展開名單；有人進來或離開時顯示提示 |
| 防濫用 | 只做發送頻率限制：每人 10 秒最多 5 則、兩則間隔至少 0.5 秒 |
| 裝置 | 手機與電腦都要好用，無橫向捲軸 |
| 兩個階段 | 階段一：假後端（展示模式），不需要任何金鑰；階段二：接上 Supabase |

## 新增功能（在畫面上怎麼看到）

| 功能 | 在畫面上怎麼看到 |
|---|---|
| 資料庫強制發言頻率限制 | 連續快速送出訊息，顯示「發言太快了，請稍等幾秒」，該則顯示「傳送失敗」。 |
| 伺服器端內容清理 | 送出含零寬字元、很多空行或頭尾空白的訊息，顯示的是清理後的版本。 |
| 匿名登入＋資料庫產生的固定 3 碼編號 | 頂部顯示「你是：小明#371」；同一瀏覽器再進入編號不變。 |
| 傳送狀態與重試 | 自己的訊息顯示「傳送中…」→「已送出」；失敗顯示「傳送失敗」與「重試」。 |
| 字數計數器 | 輸入框下方顯示「N / 500」，超過變紅並停用送出。 |
| 載入更早的訊息 | 訊息超過 50 則後，最上方出現「載入更早的訊息」；載完顯示「已經是最早的訊息」。 |
| 「正在輸入…」提示（Realtime Broadcast，和所有人即時同步） | 一邊在輸入框打字，另一邊在輸入框上方看到「某某 正在輸入…」；停止約 5 秒或對方送出訊息後消失。 |

## 刻意不做

多個房間、私訊、編輯與刪除訊息、圖片與檔案、檢舉與封鎖、管理員後台、訊息自動清除、推播通知、完整帳號制。

## 已知限制

代號可以重複（編號不同）；訊息永久保存在資料庫、畫面一次載入 50 則。詳見 `architecture.md` 第 9 節。
